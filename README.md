# Stormbrew

A roguelike deck-builder like *Slay the Spire*, built around **weather** and **brewing**.

- **Weather** changes every few turns. The player, enemies, and events can also change it, and it alters the rules for everyone in the fight.
- **Brewing** combines elements in a cauldron. Different combinations produce different results, including brews that change the weather.

Made for **Android (APK)** first, and also runs in a web browser. iOS and desktop builds may come later.

Plays in **English** and **Korean** (한국어): choose under ⚙️ Settings on the title screen. Sound, vibration and weather effects can be turned off there too.

See [PLAN.md](PLAN.md) for the full game design and development plan.

## Getting the Android app

Every push builds a debug APK on GitHub Actions:

1. Open the **Actions** tab and pick the latest **Android APK** run.
2. Download the **stormbrew-debug-apk** artifact (a zip containing the APK) and unzip it.
3. Copy the APK to your phone and open it. Android will ask you to allow installing apps from that source.

Pushing a version tag (e.g. `v0.1.0`) also creates a GitHub Release with the APK attached, which is easier to download straight from a phone.

> Each CI build is signed with a different temporary debug key, so if Android refuses to install over an older build, uninstall the old one first. A permanent signing key will be added before any store release.

## Development

Requires Node.js 22+.

```bash
npm install
npm run dev        # run in the browser with hot reload
npm test           # unit tests (Vitest)
npm run typecheck  # TypeScript checks
npm run build      # production web build in dist/
npm run balance    # balance report: 200 runs by a computer player (about 30 s)
```

Building the APK locally needs Java 21 and the Android SDK (easiest via Android Studio):

```bash
npm run android:apk   # APK in android/app/build/outputs/apk/debug/
npx cap open android  # or open the project in Android Studio
```

### Project layout

```
src/core/   game logic (no DOM), unit-tested
src/data/   content: cards, recipes, enemies, relics, events, weather cards
src/i18n/   languages: English messages (en.ts), Korean messages and content (ko*.ts)
src/ui/     rendering and theme (colors, icons), sound, vibration and the weather sky
resources/  the app icon art (icon.svg); the Android icon and splash screen use the same shapes
tests/      Vitest tests; tests/helpers has the computer players, tests/balance the balance report
android/    native Android project (generated by Capacitor)
```
